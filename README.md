# Recipe Finder (Next.js)

اپلیکیشن جستجوی دستور غذا با Next.js (App Router) + TypeScript و API سایت Spoonacular.

## اجرا

1. یک کلید رایگان از https://spoonacular.com/food-api بگیرید.
2. فایل `.env.example` را کپی کنید و اسمش را `.env.local` بگذارید، سپس کلید را داخلش بنویسید:
   ```
   SPOONACULAR_API_KEY=your_key_here
   ```
3. نصب و اجرا:
   ```bash
   npm install
   npm run dev
   ```
   سپس http://localhost:3000 را باز کنید.

## امکانات

- صفحه اصلی با نوار جستجوی بزرگ (جستجو با نام غذا یا با مواد اولیه)
- نتایج به‌صورت کارت‌های Grid، فیلتر نوع غذا / رژیم / مرتب‌سازی، و Pagination
- صفحه جزئیات: مواد لازم، مراحل تهیه، اطلاعات اضافی، دکمه ذخیره در علاقه‌مندی‌ها
- علاقه‌مندی‌ها با localStorage (حذف تکی، حذف همه، پیام خالی بودن)
- اختیاری‌ها: فیلتر پیشرفته (رژیم‌ها، کم‌کالری، زمان پخت، حساسیت‌های غذایی)، تم روشن/تاریک، دکمه اشتراک‌گذاری
- ریسپانسیو و مناسب موبایل

## ساختار

```
app/            صفحه‌ها (/, /search, /recipe/[id], /favorites, /about)
components/     کامپوننت‌ها (SearchForm, RecipeCard, Pagination, ...)
lib/            ارتباط با API (فقط سمت سرور)، ثابت‌ها، ذخیره علاقه‌مندی‌ها
```

کلید API فقط سمت سرور استفاده می‌شود و در مرورگر دیده نمی‌شود.
